# Bundled font

`fraunces-600.woff2` — [Fraunces](https://github.com/undercasetype/Fraunces),
SIL Open Font License 1.1 (see `Fraunces-OFL.txt`). Latin subset, one weight,
11 KB.

Self-hosted rather than linked from Google Fonts on purpose: this app runs on a
kitchen tablet and, in standalone desktop mode, on a machine that may have no
internet at all. A wordmark that silently falls back to the system font whenever
the house Wi-Fi is down is not much of a wordmark.

Used only for the app name in the header. Everything else is the system UI font,
which is what body text should be.
